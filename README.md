# remio-notes

> あとで、思い出せる。

[公開版を開く](https://remio-notes.vercel.app)

思いついたこと、あとで確認したい知識、期限のある用事を、ひとつのカードとして残せる個人向けノートです。分類に時間をかけずに書き始め、必要になったときは検索・タグ・使う場面から取り出せます。

## こんな人のために

- 仕事や生活のメモを、タスクやリマインダーと分けずに残したい人
- 保存した情報を「必要なとき」に見つけ直したい人
- PC・iPad・スマートフォンを行き来しながら、自分の記録を使いたい人

## できること

- 1行のメモから、期限・通知・タグ・使う場面を持つカードまでを素早く作成
- Today、今後の予定、タスク、知識、メモ、通知、完了済み、ピン留めから閲覧
- 本文・タグ・使う場面を検索して、情報を再発見
- カードの複製、アーカイブ、復元、JSONバックアップと読み込み
- Googleログインによる端末間同期。ログインしない場合も端末内だけで利用可能
- オフラインでも閲覧・記録できるPWA。再接続後に同期を再開

## 最近の変更

- アプリ名を **remio-notes** に統一し、ブラウザーのタイトル、PWA名、ファビコン、ホーム画面アイコンを更新
- iPad・スマートフォンを含む画面幅で、ナビゲーションとカード操作を迷わず行えるレイアウトに改善
- iOS / iPadOSでも表示できるPNGのホーム画面アイコンを追加し、古いキャッシュが残らないようService Workerの更新処理を改善
- Google OAuth（PKCE）とSupabaseを使った本人のカードだけの同期を追加
- 同期中の編集、削除、通信待ちの変更を保護し、アカウントごとに端末内のデータを分離

## 使い方

1. 公開版でカードを追加します。ログインしなくても使えます。
2. 端末間で使う場合は、設定からGoogleでログインします。
3. 別の端末でも同じGoogleアカウントでログインすると、同期済みのカードを確認できます。

ログイン前のカードはブラウザー内に保存され、外部サーバーへ送信されません。ログイン後はカードの同期用コピーがSupabaseに保存されます。端末内だけに残っている未同期の変更に備え、必要に応じてJSONバックアップも保存してください。

## 技術構成

- React / TypeScript / Vite
- SQLite Wasm + IndexedDB（ローカル保存・検索）
- Supabase（Google OAuth、本人専用の同期）
- Vercel（静的配信）
- Service Worker（オフライン利用）

## 自分の環境で公開する

Vercel、Supabase、Google OAuthの設定手順は[DEPLOYMENT.md](./DEPLOYMENT.md)を参照してください。公開用の環境変数にはSupabaseのProject URLとpublishable keyだけを設定します。`service_role`、Google Client Secretなどの秘密情報をGitHub・Vercelの`VITE_`変数・ブラウザーに置かないでください。

## Web版の範囲

- 通知はアプリを開いている間に確認します。ブラウザーを閉じた状態での定刻通知は対象外です。
- オフライン利用は、最初にオンラインでアプリを開いた後に有効になります。
- Tauri、ローカルLLM、Embedding検索はWeb版に含みません。

SQLite Wasm: <https://sqlite.org/wasm/doc/trunk/index.md>
