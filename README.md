# remio-notes

### 思いついたことを記録し、必要なときに思い出せる場所。

**remio-notes** は、日々の生活で得た知識や気づき、アイデア、タスク、リマインダーを一元管理する、個人向けナレッジマネジメントアプリです。

「いつか役に立ちそう」と思って保存した情報を、必要なときに見つけられなかった経験はありませんか？

remio-notes は、情報を保存するだけでなく、**必要な場面で素早く見つけ、実際の行動や判断に活用できること**を重視しています。

## コンセプト

**「記録する」から「思い出して活用する」へ。**

従来のメモアプリでは、メモ・タスク・リマインダーなどが別々に管理されることが少なくありません。しかし、実際の情報は必ずしも明確に分類できるものではありません。

例えば、「旅行前にモバイルバッテリーを確認する」という情報は、持ち物に関する知識であると同時に、旅行前に実行すべきタスクでもあり、適切なタイミングで通知してほしいリマインダーでもあります。

remio-notes では、こうした情報を一つの **Card（カード）** として管理します。

カードには必要に応じてタグ、期限、通知日時、利用場面（Context）などを設定でき、同じ情報を複数の用途で活用できます。

## 由来
このアプリの名前であるremioは 自分の知識を蓄積し、必要なときに取り出せるようにするという思いの**Remember + Me** を合わせてremioです。

## 主な特徴

### 1. 思いついた瞬間に記録

複雑なフォルダ構造や分類操作を必要とせず、思いついたことをすぐに保存できます。

タイトルやタグの設定は必須ではありません。短い一文だけでもカードとして保存できるため、記録そのものに時間をかけずに済みます。

### 2. メモ・知識・タスクを一元管理

すべての情報を共通のカード形式で管理します。

- **Notes**：日常のメモやアイデア、気づき
- **Knowledge**：覚えておきたい知識やノウハウ
- **Tasks**：期限や完了状態を持つ行動
- **Reminders**：指定した日時に通知する情報
- **Contexts**：特定の場面で思い出したい情報

これらは独立したデータ形式ではなく、一つのカードが複数の役割を持てるように設計しています。

### 3. 必要な情報を見つけるための検索

情報が増えても、必要なカードを素早く探し出せることを重視しています。

キーワードによる全文検索に加え、タグ・期限・Contextなどを組み合わせた絞り込みに対応する設計です。

将来的には意味検索や自然言語検索も取り入れ、正確なキーワードを覚えていなくても、曖昧な記憶から情報を探せる体験を目指します。

### 4. Contextによる情報の再発見

remio-notes では、「何についての情報か」だけでなく、**「いつ、どんな場面で役立つ情報か」** も管理します。

例えば、カードに「PCを購入するとき」というContextを設定しておけば、次にPCを選ぶ際に、過去に記録した注意点や比較ポイントをまとめて確認できます。

単なるキーワード検索にとどまらず、状況に応じて過去の知識を再利用できる仕組みを目指しています。

### 5. タスクとリマインダーの連携

カードにはタスクの期限（Due）と通知日時（Reminder）を個別に設定できます。

タスクを完了してもカード自体は残るため、実行した結果や新たに得た知識を追記することも可能です。

日々のタスク管理を、そのまま自分だけの知識の蓄積につなげます。

### 6. デバイス間の同期とオフライン利用

スマートフォンで記録した情報を、PCからも確認できるように、デバイス間の同期を想定しています。

データはローカルへの保存を基本とし、オフラインでも記録や閲覧ができる設計を目指します。インターネット接続が復旧した際には、変更内容を同期します。


## 目指す体験

remio-notes が目指すのは、大量の情報を美しく整理するためのツールではありません。

日々の小さな発見や学びを無理なく蓄積し、必要になったときに自然に取り出せる、自分専用の知識基盤です。

**書く → 見つける → 活用する → 学ぶ → また残す。**

この循環を、できるだけシンプルで快適な体験として実現することを目指しています。

## 開発

```sh
npm install
npm run dev
```

## 検証・ビルド

```sh
npm test
npm run build
npm run preview
```

React / TypeScript / Vite / Lucide / 公式 SQLite Wasm を使用。SQLite 本体のスナップショットを IndexedDB に保存し、FTS5 の trigram インデックスと文字一致・タグ・Context・簡易同義語の順位付けを組み合わせて検索します。入力の補助はルールによる候補提案で、候補はクリックするまで設定されません。

## 実装機能

- カードの追加・編集・削除・複製・アーカイブ・復元
- タグ、自然文の Context、期限、リマインダー、ピン留め
- タスク完了時の通知停止と知識の保持
- Today / Upcoming / Tasks / Knowledge / Memos / Reminders / Completed / Pinned / Random
- 4列ボードの列設定、リスト表示、並べ替え、タグ・状態・期限検索
- 日本語部分一致、FTS5、検索履歴、キーボードによる結果選択
- Ctrl/Cmd+K で検索、N で追加、Ctrl/Cmd+Enter で保存
- 関連カード、重複候補、ルールによるタグ・日時・Context提案
- JSONバックアップの書き出しと検証付きマージ読み込み
- レスポンシブ表示、フォーカストラップ、動きの軽減設定への対応
- ビルド時に生成される Service Worker によるオフライン利用
- Google OAuth（PKCE）によるログインと、Supabaseの本人専用カード同期
- アカウント別のローカル保存、永続化された送信待ち、削除の同期、編集競合の保護

## 一般公開と同期

Vercel用の設定は `vercel.json`、データベースは `supabase/migrations/202610090001_cards.sql` にあります。セットアップ手順は [DEPLOYMENT.md](./DEPLOYMENT.md) を参照してください。Supabaseの環境変数が未設定の場合はローカル利用だけが有効で、Googleログインは無効として表示します。

## Web版の範囲

ログイン前の本文は外部サーバーに送信しません。Googleログイン後のカードはSupabaseに保存され、同じアカウントの端末間で同期します。ローカルの保存領域はアカウント・サイトのorigin・ブラウザープロファイルごとに分かれます。以前のサイトからVercelへ移す場合はJSONバックアップを使用してください。未送信データは端末だけにあるため、バックアップも定期的に保存してください。

通知はアプリを開いている間に約15秒間隔でチェックします。バックグラウンドではブラウザーによって遅延する場合があります。閉じた状態での定刻通知、Tauri、ローカルLLM、EmbeddingはこのWeb版の対象外です。ブラウザー通知は設定画面で本人が許可したときだけ有効になります。サンプルカードはOS通知しません。

初回にサンプルカードを保存します。設定からサンプルだけを取り除けます。編集したサンプルは通常のカードとして残ります。オフライン利用は初回オンライン読み込みで Service Worker が準備された後に有効です。Web Locks に対応したブラウザーでは複数タブからの同時書き込みを防ぎます。

SQLite API: https://sqlite.org/wasm/doc/trunk/index.md
